ancient artifact dug from a lost civilisation.

## The placard

> Sticky note, c. 1500 BCE. Papyrus and beeswax. Reads: 'Do not move the grain.' Earliest known passive-aggressive memo. Gift of the Break Room.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (or `$ENTRY_OUTPUT`,
or `$OUTPUT_DIR/entry.txt`).
